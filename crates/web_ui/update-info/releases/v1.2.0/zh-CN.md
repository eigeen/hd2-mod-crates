# 1.2.0 功能更新

## 更新 Mod 版本

- 补全旧 Unit 更新流程。现在会检查 Unit 版本、旧顶点格式和 LOD 数据并修复。
- 对于 `10800437 → 10800438`，只更新 Unit 版本和旧顶点格式。其他旧版本通过安全检查后，会使用当前游戏数据更新 LOD group。
- 部件无法直接匹配时，会参考 Mod 原本装备的几何数据，减少漏配和错配。
- 移除实验性 culling 开关和相关代码。目前确认问题来自 Unit 版本和结构变化，因此不会修改 culling 数据。

以上修复只在“更新 Mod 版本”时执行。外观迁移和合并 Mod 不受影响，也不会修改 GPU 和 stream 文件。

## 兼容性与稳定性

- 有多个同名游戏资源时，优先使用确认可用的 FS-05 数据，避免读到不可用资源。
- 网页版和桌面版统一检查 Patch 配套文件。缺少必要文件时会直接提示。
- 修复桌面版 ZIP 可能写入不完整的问题。

## 使用体验

- 高级选项移入单独菜单，界面更简洁。
- 任务较大时，网页版会提示使用桌面版。
- 调整中英文说明，明确迁移、更新和合并三种功能的范围。
