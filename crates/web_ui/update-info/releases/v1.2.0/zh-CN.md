# 1.2.0 功能更新

## 更新 Mod 版本

- 补全旧 Unit 更新流程。现在会检查 Unit 版本、旧顶点格式和 LOD 数据并修复。
- 部件无法直接匹配时，会参考 Mod 原本装备的几何数据，减少漏配和错配。

以上修复只在“更新 Mod 版本”时执行。外观迁移和合并 Mod 不受影响。

## 兼容性与稳定性

- 引入资源覆盖表，避免多个同名游戏资源时选择错误的资源。此更新修复了迁移部分装备时目标错误设为民主官的问题。
- 网页版和桌面版统一检查 Patch 配套文件。缺少必要文件时会直接提示。
- 修复桌面版 ZIP 可能写入不完整的问题。

## 使用体验

- 高级选项移入单独菜单，界面更简洁。
- 任务较大时，网页版会提示使用桌面版。
