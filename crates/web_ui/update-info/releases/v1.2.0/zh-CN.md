# 1.2.0 功能更新

## 更新 Mod 版本

- 补全原版 repatcher 的旧 Unit 更新流程。现在会检查 Unit 版本、旧顶点格式和 LOD 数据，避免只改版本号后仍因结构不一致而失效。
- 对已确认的 `10800437 → 10800438` 更新，只修改 Unit 版本和旧顶点格式；其他旧版本会先完成安全检查，再从当前游戏数据同步 LOD group。
- 部件无法直接对应时，现在会参考 Mod 原本装备的几何数据继续匹配，减少部件漏配或错配。
- 已移除实验性的 culling 开关和相关改写。当前修复按 Unit 版本与结构升级处理，不会改写 culling 数据。

以上改动只用于“更新 Mod 版本”。外观迁移和手动合并 Mod 不会自动执行 Unit 版本更新，GPU 与 stream 文件也会保持原样。

## 兼容性与稳定性

- 同名游戏资源存在多个归档时，优先读取确认可用的 FS-05 数据，避免选到无法处理的资源。
- 网页版和桌面版现在使用相同的 Patch 配套文件检查，缺少必要文件时会直接说明问题。
- 修复桌面版输出 ZIP 时文件可能没有完整写入的问题。

## 使用体验

- 高级选项已收进独立菜单，常用操作更简洁。
- 网页版会在任务较大或更适合本地处理时提示使用桌面版。
- 调整了中英文说明，让迁移、更新和合并三种功能的范围更清楚。
