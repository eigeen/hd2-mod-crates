# 1.2.0 功能更新

## 头部合并

新增“头部合并”工具，可以将头盔模型合并到身体模型上。

*合并后还需要另外安装“移除头盔”Mod，用来隐藏游戏自带的头盔。*

## 合并 Mod

- 桌面版新增“合并 Mod”工具，可将多组 Patch 合并为一个 Mod，并调整冲突时的覆盖顺序。

## 外观迁移与更新 Mod 版本

- 改进外观迁移的部件匹配：无法直接匹配时，参考 Mod 原本替换的游戏装备模型，减少漏配和错配。
- 修复 FS-05 会替换到民主官的问题。
- 完善“更新 Mod 版本”的旧模型修复，处理版本和旧顶点格式，并按版本需要更新 LOD 数据。
- 大幅优化更新 Mod 时的游戏文件扫描速度。

模型版本修复需要单独运行“更新 Mod 版本”。外观迁移和合并 Mod 不会自动执行这项修复。

## 稳定性与使用体验

- 减少网页版导入和合并大型 Mod 时的内存占用，降低内存不足导致失败的概率。
- 修复部分 Mod 资源信息异常导致的读取失败；缺少必要配套文件或文件不完整时会直接提示。
- 修复桌面版 ZIP 可能写入不完整的问题。
- 统一网页版和桌面版的工具界面、任务报告和错误提示，改善进度更新时的流畅度。
- 高级选项移入单独菜单，界面更简洁。
- 网页版增加桌面版下载入口，任务较大或遇到浏览器限制时会提示使用桌面版。
